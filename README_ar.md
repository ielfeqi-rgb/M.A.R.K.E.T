**منظومة M.A.R.K.E.T v4.0.2** هي منصة مؤسسية ذاتية الاستضافة (Self-Hosted) ومخصصة لأتمتة عمليات التجارة الإلكترونية وخدمة العملاء. تجمع المنظومة بين قنوات التواصل المتعددة، ونظام إدارة الوصول المستند إلى الأدوار (RBAC)، ومحرك هوية العملاء المركبة (CRM Composite UID)، ومجدول المهام والتأخير الزمني، مع ربط واجهات النماذج اللغوية المحلية والسحابية ضمن خدمة بايثون موحدة ومستقلة بالكامل دون أي متطلبات تشغيلية لبيئة Node.js أو NPM.

## القدرات والخصائص الأساسية (الإصدار v4.0.2 للمؤسسات)

- **التحكم في الوصول القائم على الأدوار (RBAC)**: محرك مصادقة وتفويض متعدد المستويات يعتمد على خوارزمية التشفير PBKDF2 (بمعدل 100,000 دورة تشفير)، مع إدارة دورة حياة الجلسات وتطبيق مصفوفة صلاحيات وظيفية دقيقة تشمل: الإدارة التنفيذية، الدعم الفني، تقنية المعلومات، المبيعات، والعمليات.
- **مركز تسليم دعم العملاء (Customer Support Handover Center)**: واجهة تحكم مركزية تمكن مسؤولي خدمة العملاء من استلام المحادثات النشطة حصريا، وإيقاف الردود الآلية مؤقتا، والتواصل المباشر مع العميل عبر WhatsApp، مع إمكانية إعادة تفعيل الرد الآلي فور إغلاق التذكرة.
- **محرك المعرف المركب وتصنيف العملاء (Composite UID & CRM Engine)**: توليد معرف ثابت للعميل بصيغة `[PLATFORM]_[PHONE]_[INITIAL_CONTACT_TIMESTAMP]`، مع تسجيل وتحديث سجلات العميل في قاعدة البيانات وتصنيفه تلقائيا حسب درجات الأهمية (VIP، عميل عائد، عميل محتمل، عميل جديد).
- **مجدول المهام والتأخير الزمني (Time & Delay Task Scheduler)**: مشغل خلفي آلي ينفذ الإجراءات والمهام المجدولة طويلة المدى (مثل إرسال قسائم العروض بعد فترات محددة كـ 90 يوما، أو متابعة الطلبات المعلقة) مع حفظ الحالة بشكل دائم ومستمر داخل قاعدة بيانات SQLite WAL.
- **بوابة تكامل Meta (Meta Integration Gateway)**: ربط ثنائي الاتجاه يشمل واجهة Meta Graph API v19.0 لنشر المنشورات والصور، مع نقاط استقبال Webhooks مؤمنة لمعالجة التعليقات وتفاعلات العملاء في الوقت الفعلي.
- **لوحة كروت لا نهائية (Infinite 2D Cards Canvas)**: تصميم وربط مسارات الرد التفاعلي مع مغناطيسية التوصيل ومؤشرات التأخير الزمني لكل خطوة.
- **توليد الكروت البرمجية (Qwen 2.5 Coder)**: محرك توليد برمجي مخصص لتحويل متطلبات العمل إلى كروت مرئية وكود بايثون تنفيذي فوري.
- **طابور المعالجة غير المتزامن والعزل البرمجي للجلسات (Async Request Queue & Session Sandbox Isolation)**: آلية عزل وقفل على مستوى الذاكرة لكل جلسة محادثة تمنع تداخل البيانات وحالات السباق (Race Conditions)، مدعومة بطابور متعدد المسارات ومعالج تدقيق مسبق للتحقق من صحة المدخلات.
- **التشغيل المباشر بدون NPM (Zero-NPM Standalone Deployment)**: تجميع الواجهة الأمامية بالكامل كملفات ثابتة مدمجة يتم تقديمها مباشرة عبر خادم FastAPI على منفذ موحد (8000)، مما يلغي الحاجة لتشغيل أي خوادم تطويرية أو أدوات Node.js أثناء التشغيل الفعلي.

## دليل البدء والتشغيل السريع

### 1. المتطلبات الأساسية
- بيئة Python 3.10+ (يوصى باستخدام Python 3.12)
- محرك SQLite 3.35+
- بيئة Docker و Docker Compose (اختياري للتشغيل داخل حاويات)

### 2. التشغيل المباشر

```bash
# استنساخ المستودع
git clone https://github.com/ielfeqi-rgb/M.A.R.K.E.T.git
cd M.A.R.K.E.T

# تثبيت الحزم والمتطلبات
pip install -r requirements.txt

# بدء تشغيل المنظومة الموحدة
python3 main.py
```

### 3. الوصول إلى مركز التحكم
- واجهة التحكم المؤسسية الموحدة: http://localhost:8000
- التوثيق التفاعلي للواجهات البرمجية (Swagger): http://localhost:8000/docs
- مواصفات OpenAPI بصيغة JSON: http://localhost:8000/openapi.json

## شكر وتقدير للمشاريع مفتوحة المصدر

نبني هذه المنظومة على عمالقة البرمجيات مفتوحة المصدر:

- **FastAPI** -- بواسطة Sebastian Ramirez (@tiangolo).
- **Uvicorn** -- خادم الـ ASGI فائق السرعة.
- **Qwen Models** -- نماذج الذكاء الاصطناعي المتقدمة من Alibaba Cloud.
- **llama.cpp** -- محرك تشغيل نماذج الذكاء محليا بكفاءة C/C++.
- **OpenWA / WPPConnect** -- بوابة أتمتة واتساب.
- **SQLite** -- محرك التخزين والبيانات فائق السرعة بنمط WAL.
- **Lucide** -- مكتبة الأيقونات العصرية.
- **Tailwind CSS** -- إطار عمل التنسيق وتصميم الواجهات.
