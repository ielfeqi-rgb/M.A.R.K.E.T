#  Embedded LTS Binary Directory

ضع ثنائي `llama-server` المستقر هنا ليعمل المحرك مباشرة بدون تشغيل أي تنزيل أو تجميع!

- **اسم الملف**: `llama-server` (على Linux) أو `llama-server.exe` (على Windows)
- **المسار**: `omnicontext_v2/bin/llama-server`

عند وجود هذا الملف داخل مجلد المشروع، يتعرف عليه M.A.R.K.E.T كـ LTS Engine مدمج كأولوية أولى تلقائياً.
